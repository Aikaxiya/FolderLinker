# 文件夹联接器

把大文件夹搬到其它磁盘，原路径留一个目录联接（Junction）。迁移后原路径照常访问，数据实际放在新位置，C 盘空间立刻释放。

## 安全性

流程是"先复制、再改名、最后建联接"，任何一步失败都能回到原状：

| 阶段   | 动作                                   | 失败后果          |
|------|--------------------------------------|---------------|
| 预检   | 只读检查路径、联接状态、同名冲突、目标盘剩余空间、系统关键目录、能否改名 | 直接拒绝，不动任何文件   |
| 复制   | 源 → `目标\源目录名`，逐文件复制并保留时间戳            | 删掉已复制的部分，源不动  |
| 校验   | 比对文件数、总字节、逐文件路径与大小（可选 SHA-256）       | 删掉目标副本，源不动    |
| 改名   | 源目录改名为 `源名.__bak_时间戳`（同盘瞬时改名，不搬数据）   | 被占用就报错，源名字不变  |
| 建联接  | 在原路径创建 Junction 指向目标                 | 失败则改回原名       |
| 穿透验证 | 通过原路径读一个文件比对大小                       | 失败则删联接 + 改回原名 |
| 清理   | 上一步通过才删 `.__bak`                     | —             |

任何时刻磁盘上都至少有一份完整数据，中途失败 100% 可复原。

## 使用

1. 双击 `FolderLinker.exe`（无控制台、无地址栏，窗口 1280×800）
2. 选**源文件夹**：要搬走的目录，也可以直接粘贴路径
3. 选**目标文件夹**：文件实际存放的父目录，程序会在里面自动建同名子目录
4. 选校验强度：**快速**（文件数 + 总字节）或**严格**（逐文件 SHA-256）
5. 点**开始迁移**

完成后原路径会显示成带快捷方式角标的目录，程序读写完全无感。

## 界面

- 固定 1280×800 窗口，不能拖拽缩放（可最大化），位置会记住
- 路径框支持粘贴带引号路径、末尾多余反斜杠、`%LOCALAPPDATA%` 这类变量；回车生效，Esc 还原
- 选到系统保护路径（如 `C:\Windows`）会**当场提示原因并把这一侧的路径清空**，不等到点"开始迁移"才报错
- 深浅色主题一键切换，选择会记住
- 迁移记录每条都能**撤销**或**删除记录**，删除只删记录、不动文件
- **查占用**：源文件夹右侧的锁图标可以查出哪个进程占着这个目录（扫描系统句柄表，约 5 秒），列表里能直接结束进程
- 纯容器窗口：独立浏览器配置目录，关掉了同步、账号推广、翻译、崩溃恢复气泡；`F12`、`Ctrl+Shift+I/J/C`、右键"检查"都已屏蔽
- 确认框是页面内自绘的，不是浏览器那种对话框

## 撤销

1. 校验联接指向与记录一致
2. 删除联接 → 把数据搬回原路径 → 校验内容一致 → 清理目标副本
3. 中途失败会自动重建联接，数据始终在目标位置完好

## 环境要求

- Windows 10 / 11 x64
- 无需管理员权限（Junction 普通用户即可创建）
- 界面依赖系统自带的 Edge 或 Chrome

## 开发与构建

```bash
npm start            # 源码运行
npm run build        # 打包 dist/FolderLinker.exe（单文件，约 59MB）
npm run icon         # 重新生成图标（改了 assets/icon/*.html 后）
node scripts/e2e.js  # 端到端测试：迁移 → 校验 → 联接 → 撤销
```

构建分四步（`scripts/build.js`）：生成图标 → 把图标和版本信息写进 pkg 的基础二进制 → pkg 打包 → 把 PE 子系统改成 GUI（去掉黑窗）。
图标和版本信息必须在 pkg 追加载荷**之前**写进基础二进制，否则载荷位置错位，程序一启动就崩。

## 运行时数据

```
%LOCALAPPDATA%\FolderLinker\
├─ journal.json     迁移记录（最多 100 条）
├─ window.json      窗口位置
├─ browser\         界面窗口的浏览器配置目录（可随时删除）
└─ logs\            按日期分文件的运行日志
```

程序目录不留任何配置，删掉 exe 即可卸载。

## 危险路径（会被直接拒绝）

规则写在 `src/core/preflight.js` 的 `checkProtectedPath()` 里，共三个数组（`trees` / `exact` / `risky`），
改规则只改这三个数组即可。实际路径**取自环境变量**，所以系统装在 D 盘时拦的就是 `D:\Windows`。

| 判定           | 路径                                                                                  | 说明                         |
|--------------|-------------------------------------------------------------------------------------|----------------------------|
| ❌ 拒绝         | 盘符根：`C:\`、`D:\` …                                                                   | 不允许迁移整个分区                  |
| ❌ 拒绝（含全部子目录） | `%SystemRoot%`，通常是 `C:\Windows`                                                     | `C:\Windows\Temp` 这类子目录也拒绝 |
| ❌ 拒绝（含全部子目录） | `<盘符>\System Volume Information`、`<盘符>\$Recycle.Bin`、`<盘符>\Recovery`、`<盘符>\Boot`    | 系统卷信息、回收站、恢复、启动目录          |
| ❌ 拒绝（仅目录本身）  | `<盘符>\Users`、`%USERPROFILE%`、`%ProgramData%`、`%ProgramFiles%`、`%ProgramFiles(x86)%` | 它们**下面的具体文件夹允许**迁移         |
| ⚠️ 警告（可继续）   | `%ProgramFiles%` / `%ProgramFiles(x86)%` 下的子目录                                      | 迁移后该程序可能无法升级或卸载            |

**两处校验，规则同一个函数**：

1. 选择/输入路径时（`/api/inspect`）——命中就当场弹提示，并把这一侧的路径**清空**，输入框下方留红字说明原因
2. 点"开始迁移"前（`/api/plan` 的预检）——兜底再查一次，命中直接拒绝，不动任何文件

## 已知限制

- **同盘迁移**：仍走"复制 + 删除"，为了保留回滚能力
- **源内嵌联接**：不会被跟随，日志会记录跳过项，避免循环引用
- **云同步目录**：OneDrive 等工具不跟随 Junction，迁移后该目录不在同步范围内
- **目录被占用时无法迁移**：Junction 必须建在"路径上已经没有东西"的位置，所以流程要先给原目录改名；
  只要还有程序占着它（编辑器打开着、终端窗口停在里面、同步盘/杀软在扫描），Windows 就会拒绝改名（EPERM）。
  程序会重试 3 次（占用常常是瞬时的，比如日志正在写），仍失败就用「检查」按钮查出占用进程
